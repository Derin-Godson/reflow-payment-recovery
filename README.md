# Reflow — Intelligent Payment Recovery

Reflow is an intelligent payment recovery and subscription churn prevention system.

It analyzes failed recurring payments, classifies the failure reason, selects an appropriate recovery action, and tracks the outcome.

## Core Pipeline

Payment Failure  
→ Decline Classification  
→ Decision Engine  
→ Guardrails  
→ Recovery Action  
→ Outcome Tracking

## Features

- Payment failure classification
- Intelligent retry decisions
- Retry scheduling
- Guardrails for unsafe retries
- Shadow-mode simulation
- Payment recovery analytics
- Razorpay integration
- Payment failure simulator
- Audit logging

## Tech Stack

- Node.js
- JavaScript
- Razorpay
- SQLite
